# 4–7세 진료 놀이: 근거와 시제품 제안

확인일: 2026-10-09. 먼저 도구를 만져서 재미있는 반응을 발견하고, 그 반응으로 도구의 실제 목적을 알게 만드는 방향을 제안한다. 아래 놀이 규칙과 수치는 **제품 설계 가설**이며, 임상 절차나 검증된 불안 치료법이 아니다.

## 구현에 적용할 7개 규칙

1. **조작하자마자 반응한다.** 도구에 손이 닿으면 움직임·빛·소리가 바로 달라진다. 약 0.2초 안에 첫 반응을 주는 것을 시제품 목표로 삼되, 이 수치를 발달 연구 결과로 설명하지 않는다. 도구를 놓았을 때도 반응하게 한다.
2. **한 장면에서 한 행동이 먼저 보인다.** 큰 몸의 일부분과 도구 하나를 보여준다. 청진기는 듣고, 빛은 보이게 하고, 커프는 부풀었다 풀린다. 아이가 보는 화면에서 레이어 목록·절개 단면·좌표·편집 패널을 없앤다. 캐릭터를 추가하지 않아도 아이가 검사를 해보는 역할 놀이를 할 수 있다.
3. **아이에게 순서와 속도를 맡긴다.** 탐색 순서를 바꿀 수 있고 이미 발견한 곳에도 다시 도구를 댈 수 있다. 완료 후에도 곧바로 화면을 닫지 않는다. 멈춤과 다른 놀이 선택은 항상 가능하게 한다.
4. **반복하면 조금 다른 재미가 생긴다.** 도구가 살짝 흔들리거나, 들었던 소리가 다시 나오거나, 빛을 따라 작은 이름표가 나타난다. 유머는 도구·리듬·소리에서 만든다. 청진기가 심장을 수리하거나 목을 비추면 염증이 사라지는 연출은 사용하지 않는다.
5. **읽기와 정밀 드래그를 필수로 만들지 않는다.** 안내는 짧은 한 문장과 조작 시범으로 시작한다. 각 드래그에는 같은 결과를 내는 탭 버튼을 둔다. 48px 이상의 버튼은 접근성 구현 목표이며 4세의 운동 능력에 대한 보편적 기준이 아니다. 소리 끄기와 움직임 줄이기를 제공한다.
6. **검사 목적을 반응에 연결한다.** “빛으로 살펴봤어”, “소리를 들었어”처럼 방금 한 행동을 한 문장으로 짚는다. 숫자를 건강 판정이나 승패로 사용하지 않는다. 정답 퀴즈·고통 참기·가만히 있기 성공 점수로 다음 놀이를 잠그지 않는다.
7. **함께하기와 거절 모두 자연스럽게 만든다.** 보호자와 쿵쿵 소리를 흉내 내거나 서로 도구 역할을 맡는 선택을 둔다. “무서울 수도 있어”, “쉬어도 돼”를 짧게 전달한다. 실제 접종·채혈은 따끔할 수 있으므로 “전혀 안 아파”라고 약속하지 않는다.

## 기존 10개 절차별 놀이 제안

아래 단계는 화면 속 놀이 흐름이다. 실제 신체에 도구를 사용하라는 안내나 의료진의 임상 수행 절차가 아니다. 그림은 큰 몸의 일부분과 도구를 중심으로 만들고, 기관 레이어를 여닫는 UI를 두지 않는다. 의료 핵심은 기존 절차 출처의 원문을 다시 확인했다.

## 먼저 확인할 시제품

청진기의 소리 찾기와 목의 빛 탐색을 먼저 비교한다. 접종·채혈은 조작의 재미와 별개로 실제 경험·두려움의 차이를 확인한다. 4–5세와 6–7세를 나눠 읽기 경험, 손 조작, 기존 병원 경험을 기록한다. 이 분류는 관찰 계획이며 연령마다 같은 행동을 한다는 주장이 아니다.

관찰 질문은 네 가지다: 말로 설명받기 전에 첫 행동을 찾는가, 반응을 보고 스스로 반복하는가, 도구가 무엇을 하는지 행동이나 한 문장으로 표현하는가, 싫을 때 스스로 멈추거나 넘길 수 있는가. 목적을 설명하는 질문은 선택이며 통과 조건이 아니다. 머문 시간이나 완료율만으로 재미·학습·불안 감소를 입증하지 않는다.
