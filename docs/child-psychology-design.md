# 청진 놀이의 아동 심리 설계

2026-10-09. 4–7세를 설계 대상으로 하는 시안이다. 최신 요청은 의인화 동물 환자와 사람 의사가 있는 한 3D 진료실에서 사물을 직접 고르고 조작하는 것이다. 현재는 청진·주사·겨드랑이 체온을 실제 토끼에 조작하고, 귀·목·코·배는 독립 검사 객체로 전환하는 틀이다. 독립 부위의 Blender 미술 교체와 게임 통합은 진행 중이다. 실제 아동의 재미·이해·불안 감소나 임상 효과를 검증한 제품은 아니다.

## 근거와 설계 가설

[놀이 연구](play-research.md)의 공식 게임 설명과 UNICEF/NHS 자료를 참고하되 관찰된 제품 특징과 프로젝트의 설계 가설을 구분한다. 첨부 참고에서는 큰 대상·직접 조작·같은 세계의 일관성을 차용한다. 최신 명시적 캐릭터 허용에 따라 동물 환자와 사람 의사를 포함한다. 이전 캐릭터 폐기는 현재 제작 지시가 아니다. 게임의 미검증 인기 수치와 다른 연령 연구의 임상 효과를 재인용하지 않는다.

[UNICEF/LEGO Foundation 놀이 자료](https://www.unicef.org/sites/default/files/2018-12/UNICEF-Lego-Foundation-Learning-through-Play.pdf)는 즐거움·의미·적극적 참여·반복·사회적 상호작용과 아이의 선택권을 설명한다. 이를 큰 3D 사물의 즉각적인 반응과 반복 청진으로 옮기는 것은 이 프로젝트의 해석이다. [NHS 소아 임상심리 안내](https://www.torbayandsouthdevon.nhs.uk/services/clinical-health-psychology/paediatric-psychology/preparing-for-hospital/)는 아이가 걱정하는 내용을 듣고 아이 주도로 준비하도록 권한다. 공포는 정보 부족 외에도 통제감 변화·이전 경험·실제 불편함과 관련될 수 있다. 아는 아이도 무서울 수 있다.

| 설계 원칙 | 현재 적용 | 남은 관찰 |
| --- | --- | --- |
| 행동과 결과가 이어짐 | 청진기 끝을 잡아 환자 표면에 대면 위치에 맞는 소리가 나고, 놓으면 멈춤 | 첫 행동을 찾고 위치/소리의 관계를 알아보는가 |
| 몸과 도구의 역할 놀이 | 앉은 토끼 환자와 걷는 사람 의사, 실제 기구·귀 연결관 | 자기 경험과 연결하되 실제 진료 절차로 오해하지 않는가 |
| 반복과 선택 | 다시 듣기, 놀이/청진 위치 수정, 쉬기와 다시 하기 | 스스로 반복하고 싫을 때 멈출 수 있는가 |
| 짧은 글과 듣기 | 같은 환자 얼굴의 지속 대화창, 짧은 자막·선택 가능한 자동 TTS | 어휘·음량·읽기 부담이 연령/경험에 맞는가 |
| 소리가 목적을 전달함 | 심장·숨·장 세 종류의 로컬 합성 소리, 듣는 동안에도 짧은 토리 설명 유지 | 소리를 구분하며 청진기가 '듣는 도구'임을 알 수 있는가 |
| 실수에도 다시 선택 | 다른 기구의 짧은 소리/빨간 윤곽, 맞는 기구의 초록 윤곽 | 여섯 기구 선택과 색/소리가 부담스럽거나 벌점처럼 느껴지지 않는가 |

동물의 머리·보이는 목·가슴·배·양팔·양다리는 이어진 실제 모델에서 확인한다. 의인화 토끼의 얼굴은 단순한 친근함의 가설이며 귀여움이 아동 선호로 검증됐다는 뜻은 아니다. 미술·색·재질을 한 진료실에서 일관되게 맞추고 기구 카드나 장면 전체 PNG로 사물 조작을 대신하지 않는다. 실제 환자 표면을 조작하며 기관 층 UI·단계 버튼·점수·제한시간을 두지 않는다. 직접 제스처 중심인 현재 방식을 접근성이 검증된 인터페이스라고 주장하지 않는다.

기구 선택·청진 위치 발견·놀이 완료는 동작을 했다는 뜻이다. 이해 부족·실패·용기·진료 비협조로 판정하지 않는다. 청진 소리는 합성된 교육 예시이고 실제 환자 녹음·진단 결과가 아니다. 도구를 대면 장기가 고쳐지거나 나쁜 소리가 지워지는 연출을 넣지 않는다. 다른 과정도 예방접종은 예방, 검사는 정보 관찰이라는 목적을 유지한다.

## 음성과 데이터의 범위

대화창 자동 읽기는 사용자 조작 뒤 로컬 TTS가 준비됐을 때 동작한다. 마이크 입력과 안내 재생의 상태는 분리한다. 사용자가 토리에게 말하기로 녹음을 시작하고 답변해줘 토리야!로 명시적으로 제출하면 ASR → Luna → 로컬 TTS로 답한다. 침묵 자동 제출·자동 재녹음은 하지 않으며, 녹음 동안 안내 재생을 멈춰 아이가 말을 끝낼 통제권을 갖게 한다. 답변은 실제 음성 시작에 맞춰 작은 하단 말풍선에 나오며 종료 5초 후 숨긴다. 성인 합성 발화로 실제 API 파이프라인은 확인했지만 아동 발화 정확도·선호·임상 효과는 미검증이다.

카메라와 얼굴 관찰 기능은 제거했다. 검사 뒤 짧은 목적 질문과 아이의 음성 답변으로 추가 설명을 제안한다. 서버의 `learningCheck` 보조 응답 계약은 얼굴 단서를 제외한다. `understood`/`revisit`/`unclear`는 미검증 보조 신호이며 침묵·전사 오류·API 오류를 이해 부족으로 기록하지 않는다.

방문 상태는 명시적 플랜과 청진 위치를 표시하는 계약이다. 증상 단서로 검사·진단을 자동 추론하지 않는다. 체험 상태와 앱의 로컬 수정, 향후 의료진 제공 상태를 구분한다. 실제 병원 제공자·인증 정보는 아직 연결되지 않았다. 전체 방문 상태·ID·별명을 AI로 그대로 전달하지 않는다.

동작 기록 외에 일반 질문·답변과 목적 질문·피드백을 텍스트 LearningJournal로 기록한다. 동의 조건을 통과한 기록은 서버의 durable outbox에서 보호자·의사 두 제공자에게 독립 전달하도록 설계했다. 두 실제 서버와 공유 웹은 아직 없으므로 제공자가 없으면 pending으로 남는다. 음성 원본·영상은 로그에 포함하지 않으며 기록을 아동 능력 평가로 사용하지 않는다.

## 다음 관찰

4–5세와 6–7세에서 읽기·손 조작·병원 경험을 구분해, 큰 기구를 잡는가, 몸 표시를 찾는가, 소리 뒤 스스로 반복하는가, 목적을 말이나 행동으로 표현하는가, 싫을 때 멈출 수 있는가를 관찰한다. 설명하기는 선택이며 정답을 요구하는 통과 조건이 아니다. 완료율·머문 시간만으로 재미나 불안 감소를 주장하지 않는다.

임상 청진 위치·소리 적합성은 의료진 검수, 의자/발/목·기구 관·touch·작은 화면·취소 동작은 최종 통합 QA가 필요하다. 모델은 상징적 시안이며 표준 해부도가 아니다. 자동 테스트 83개 통과 보고는 계약/입력 검증 범위이며 아동/임상 검증을 대신하지 않는다. 이전 앞면 거울·카드 선택 QA를 현재 화면 근거로 사용하지 않는다. 이 개발상 제한을 어린이 화면의 긴 설명으로 옮기지 않는다.
