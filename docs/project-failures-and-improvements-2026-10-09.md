## 1. 정리 범위와 판정 원칙

프로젝트 경로가 일치하는 아래 기존 채팅 **5개**를 확인했다. 앱 채팅 목록에서 보이지 않던 이미지 제작 채팅도 메인 채팅의 생성 기록과 로컬 세션 메타데이터를 통해 찾아 읽었다. 보관된 채팅 목록에서는 이 프로젝트의 추가 채팅을 찾지 못했다. 하위 에이전트의 결과는 부모 채팅에 수록된 보고와 저장된 검증 파일을 활용했으며, 모든 하위 에이전트의 별도 대화 원문까지 각각 열람한 것은 아니다.

**‘실패’와 ‘요구사항 변경’을 구분했다.** 사용자가 방향을 바꾼 사실만으로 이전 구현이 잘못됐다고 판단하지 않는다. 사용자의 불만·오동작 보고는 중요한 근거지만, 재현과 원인 확인이 없으면 ‘보고’로 표시한다. 구현 완료라는 채팅 설명도 실제 브라우저·소리·외부 전달 검증과 구분한다.

상태 표기:

- **검증됨**: 해당 범위를 확인한 테스트·로더·브라우저 보고가 있다. 현재 모든 기능의 완성을 뜻하지 않는다.
- **반영됨**: 채팅 또는 현재 소스에서 변경을 확인했지만 해당 최신 조합의 최종 검증은 남았다.
- **진행 중**: 구현·제작·통합·재검수가 이어지고 있다.
- **미해결/미검증**: 완료 근거가 없거나 확인된 한계가 남았다.
- **변경/중단**: 새 요구사항으로 기존 방향이 대체됐다.
- **정정됨**: 최초 보고가 후속 사용자 설명으로 수정됐다.

## 2. 사례별 중요도 기준

아래 중요도는 **이 문서에서 영향과 우선순위를 평가한 것**이다. 채팅에서 이미 합의된 장애 등급이나 임상 위험 등급은 아니다. 해결된 사례도 재발 시 영향을 기준으로 중요도를 유지했다.

| 중요도 | 의미 | 판단 기준 |
| --- | --- | --- |
| **P0 · 최우선** | 즉시 차단·확인이 필요한 신뢰성 문제 | 실제로 말하지 않은 내용이 아이 발화로 표시되고 후속 답변·기록으로 이어질 수 있음 |
| **P1 · 높음** | 핵심 체험·진행·응답을 깨뜨림 | 게임 목적 불일치, 조작·전환 실패, 서버 종료, 음성 인식·재생 단절, 배포 실행 누락 |
| **P2 · 중간** | 사용성·품질·운영 효율을 저하시킴 | 구도·배치·명칭·목소리·자산 품질·문서 불일치·검증 부족 |

## 12. 반복 실패에서 도출한 개선 원칙

1. **핵심 체험부터 끝까지 확인한다.** 새 장면 수를 늘리기 전에 한 과정의 선택→집기→부위→조작→소리→문답→완료를 실제 입력으로 확인한다.
2. **외형과 판정을 함께 만든다.** PNG는 알파·접촉점, GLB는 실제 표면·앵커·지지면·camera/world 좌표를 같이 검수한다.
3. **입력·생성·재생·게임 진행의 수명을 분리한다.** 녹음 취소가 이미 수락한 답변을 끊지 않게 하되, 실제 화면 전환은 과거 출력까지 정리한다.
4. **아이 발화와 모델 결과를 구분한다.** prompt 복사·무음·잘림·오인식은 질문과 이해 판정에 그대로 흘려보내지 않는다.
5. **만들었다·연결했다·검증했다를 구분한다.** 자산 게시, 앱 로딩, 실제 선택·접촉, 사용자 선호, 실제 API, 외부 전달은 각각 다른 완료 조건이다.
6. **중간 검토를 작게 반복한다.** 한 장면·한 목소리 샘플·한 조작 흐름을 먼저 확인하면 전체 교체 비용이 줄어든다.
7. **진행 중 문서를 현재 계약으로 갱신한다.** 상시 듣기 패치, 과거 캐릭터·거울·카메라·SVG 지시와 오래된 QA가 최신 기준을 덮어쓰지 않게 한다.

## 13. 검증 근거를 읽을 때의 주의점

- 기본 테스트 **42→73→74→81개**, 음성 독립·서버 테스트 **33→78→82개** 등은 서로 다른 시점·명령·범위다. 합산해서 현재 총 통과 수로 발표하지 않는다. 이번 회고 작성 과정에서는 테스트를 새로 실행하지 않았다.
- 실제 초기 ASR·Luna·TTS HTTP 연결은 확인됐다. 이후 수동 UI·최신 자산·실제 마이크가 결합된 전체 지연은 별도다.
- 청진 심장 소리의 최신 실제 터치 QA는 존재하지만, 그것만으로 최신 심장·호흡·장 모든 소리의 사용자 청감이 확인된 것은 아니다.
- 귀 GLB의 닫힌 topology·앵커 일치는 확인됐다. 밑동 돌출이나 실제 앱 카메라·이경 조작 품질은 다른 검수다.
- `LearningJournal`·outbox 저장과 202 수락은 실제 보호자·의사 서버의 수신 성공이 아니다.
- 파일과 과거 채팅에 의료 자료 링크가 있어도 이번 문서는 의료 지침을 새로 검증한 문서가 아니다. 게임 값·합성 소리·잠정 학습 신호를 임상 기준으로 해석하지 않는다.
