# 진료랑 놀아요!

4–7세를 설계 대상으로 하는 진료 놀이입니다. 현재 제공하는 과정은 **청진기·귀·예방접종·체온·배 살펴보기 5개**입니다. 꾸며진 3D 진료실에서 기구를 직접 고르고, 사람 의사가 기구를 가져오면 의자에 앉은 토끼 환자의 몸 부위를 선택합니다. 이후 실제 환자 GLB 표면에 청진기 끝을 옮겨 심장·숨·장 소리 예시를 듣습니다. 주사·체온은 실제 토끼 몸에 직접 조작하고, 귀는 같은 토끼의 한쪽 귀를 분리한 모형과 귓길·고막을 사용합니다. 목·코·혈압·산소·피 검사는 현재 메뉴와 의사 방문 계획에서 제외했습니다.

## 실행

Node.js 24 이상을 사용합니다. 로컬 Three.js 번들은 `public/vendor/three.js`에 포함됩니다.

```powershell
npm install
npm start
```

[놀이 화면](http://127.0.0.1:3000/)의 기본은 `custom` 플랜의 청진기 단일 과정입니다. 심장·왼쪽 숨·오른쪽 숨·배 네 위치를 체험용으로 제공합니다. `아이 상태와 진찰 순서`에서 별명·나이·상태 단서·명시적인 과정 순서와 청진 위치를 바꿀 수 있습니다. 데모 값은 실제 환자 정보나 의료진의 진단·검사 지시가 아닙니다.

## 현재 화면과 조작

- 기본 진료실 기구는 청진기·체온계·이경·주사기 네 종류입니다. 과정의 정답 소모품은 필요할 때만 추가하며 혈압 커프·산소포화도 집게·검사 튜브는 기본 선택에서 제외합니다. 이름은 완전히 투명한 배경에 데스크톱 22px/작은 가로 화면 18px로 표시합니다. 공식 이름인 **이경**을 유지합니다. 오답에는 짧은 소리와 빨간 윤곽, 정답에는 초록 윤곽 뒤 의사 이동·기구 가져오기·검사 진입을 연결합니다. 검사 중 가구는 움직이지 않습니다.
- 토끼 환자는 실제 rigged GLB로 진찰 의자에 앉습니다. 사람 의사도 실제 GLB와 걷기 clip을 사용합니다. 좌상단의 고대비 대화창에는 같은 환자 GLB를 로컬에서 렌더한 얼굴 PNG와 자막을 둡니다.
- 몸 부위 선택과 청진 위치는 실제 환자 표면의 일부 색을 바꿔 보여줍니다. 부위 선택에는 초록/붉은색, 필요한 청진 위치에는 밝은 노랑과 발견 후 초록을 사용하며 원형 overlay나 SVG 표시를 덧붙이지 않습니다.
- 청진기 끝을 직접 잡아 색이 바뀐 환자 표면에 옮기고 유지합니다. 가까운 이웃 위치가 겹치지 않도록 반지름과 가장 가까운 위치 판정을 사용하며, 실제 경과 시간으로 1.6초 유지하면 발견합니다. 의사 귀 쪽 연결관이 이어지고 위치에 맞는 심장·숨·장 소리가 납니다. 맞게 놓고 손을 떼어도 소리를 듣고 대기할 수 있습니다. 토리 설명과 청진 소리는 함께 재생합니다. 유지 시간은 놀이 판정값입니다.
- 본 놀이에 단계 버튼·점수·제한시간·투명한 기관 층 UI를 두지 않습니다. 실제 3D 사물과 환자 표면을 대상으로 조작합니다. 이전 2D SVG renderer·거대한 앞면 거울·카드식 기구 선택은 현재 진입 경로가 아닙니다.

청진 소리는 브라우저에서 만든 **교육용 합성 예시**입니다. 실제 환자 녹음·진단 자료가 아니며 청진 위치·유지 시간도 임상 수행 지침이 아닙니다. 청진기로 심장·폐·장 소리를 듣는 역할은 [Cleveland Clinic 청진 설명](https://my.clevelandclinic.org/health/diagnostics/23080-auscultation)을 참고합니다. 원문이 설명하는 다른 부위까지 구현한 것은 아닙니다.

현재 어린이 메뉴와 신규 의사 계획에는 청진·귀·예방접종·체온·배 다섯 과정만 제공합니다. 서버가 명시한 플랜에 아직 제공하지 않는 과정이 있으면 임의로 다른 과정으로 바꾸지 않고 준비 중 안내를 보여줍니다.

휴대폰은 **가로 화면 전용**입니다. 세로 화면에서는 회전 안내를 띄우고 게임·재생 음성·마이크를 멈춥니다. 가로로 돌아오면 쉬기 상태를 보존하며, 마이크는 말하기 버튼을 다시 눌러 시작합니다. 표정 카메라는 제거했습니다. 작은 가로 화면에는 전용 말풍선 배치를 사용합니다. 가로 전용 회전·멈춤·진행 유지 동작은 실제 포인터 브라우저 QA에서 확인했습니다.

## 방문 정보 연결

`GET /api/visit-state`는 방문 상태 계약을 제공합니다. 기본 설정에서는 청진기 체험용 상태를 반환합니다. 향후 서버에서 `CLINIC_VISIT_STATE_URL`과 선택적인 `CLINIC_SERVICE_TOKEN`을 설정하면 방문 제공자에 요청하고 응답을 검증합니다. 실제 병원 서버·인증 정보·환자 시스템은 아직 연결되지 않았습니다.

`plan.steps`는 명시적으로 주어진 순서이며 상태 단서로 자동 진단하거나 검사 순서를 추론하지 않습니다. `plan.auscultation.sites`는 `heart`, `breath-left`, `breath-right`, `bowel` 중 1–4개로 제한됩니다. 같은 방문의 새 `revision`만 반영하며 앱의 로컬 수정과 제공자 상태를 구분합니다. 클라이언트 URL에서 환자를 조회하지 않습니다. 상세 계약은 [틀 인계](docs/framework-handoff.md)에 있습니다.

## 음성과 관찰

좌상단 환자 대화창은 짧은 자막과 로컬 Supertonic TTS 읽기를 연결합니다. 사용자 조작 뒤 음성 재생이 허용되며 자동 읽기를 끌 수 있습니다. 현재 로컬 TTS 준비 상태는 확인됐습니다.

```powershell
# 처음 한 번
powershell -ExecutionPolicy Bypass -File voice/setup.ps1
# 다음 실행부터 별도 터미널
voice/.venv/Scripts/python.exe voice/service.py
```

음성 입력은 **토리에게 말하기 → 녹음 → 답변해줘 토리야!** 두 번 누르는 방식입니다. 처음 버튼에서만 마이크를 켜며, 말을 끝내고 두 번째 버튼을 누를 때만 전사와 AI 응답을 요청합니다. 침묵으로 자동 제출하지 않습니다. 검사 목적을 확인하는 WHY 단계만 질문 음성이 끝난 뒤 자동으로 듣기를 시작하며, 직접 제출 버튼을 누릅니다. 녹음 중에는 새 안내 음성을 억제하고 제출 후 마이크를 해제합니다. 토리의 자막은 실제 음성 재생 시작에 맞춰 별도 하단 말풍선에 나오며 종료 5초 후 숨깁니다. 긴 답은 문장별로 재생하고 다음 한 문장을 미리 합성합니다.

배포용 `.env`의 키를 서버에서 읽으며 앱에 키 입력 기능은 없습니다. 기본 답변 모델은 `gpt-6-luna`, 전사는 `gpt-4o-mini-transcribe`, 저장은 `store:false`입니다. 성인용 합성 음성 fixture로 실제 ASR·Luna·TTS HTTP 파이프라인을 검증했습니다([실증 기록](artifacts/pipeline-live-report.json)). 측정 당시 ASR 1.64초, 일반 답변 1.76초였고 전체 답변 TTS는 25.10초였습니다. 이후 로컬 CPU 대기 제거와 문장 분할을 적용했으며 짧은 첫 문장의 TTS 합성은 1.51초를 확인했습니다. 이 수치는 서로 다른 요청의 측정값이며 현재 전체 종단 지연이나 실제 아동 발화 정확도를 입증하지 않습니다.

검사가 끝나면 “이건 왜 검사하는 걸까?”를 묻고, 아이의 말에 짧은 목적 설명과 필요한 확인 질문을 제공합니다. 최대 3차례 뒤 놀이를 마무리하며 “잘했어!”와 다시 하기/다음 진찰을 제공합니다. AI의 understood/revisit/unclear는 대화 진행을 위한 잠정적인 표시이며 임상적으로 검증된 평가가 아닙니다. 표정 영상은 수집하지 않습니다. 실제 어린이의 외부 대화·전사는 기존 참가자/보호자 확인 및 기본 차단 조건을 유지합니다.

`LearningJournal`은 일반 질의응답과 검사 후 문답을 글 기록으로 보내고, 서버는 `.data/learning-outbox`에 원자적으로 저장합니다. `/api/learning-log`의 202는 서버에 대기 기록을 수락했다는 뜻입니다. `GUARDIAN_LOG_URL`과 `CLINICIAN_LOG_URL`이 설정되지 않아 현재 두 수신처의 전달 상태는 pending/not_configured입니다. 실제 보호자·의사 웹/인증/서버는 아직 배포하지 않았습니다. 원본 음성과 영상은 이 기록에 넣지 않습니다. [음성 문서](voice/README.md)와 [배포 문서](docs/deployment.md)를 참고합니다.

## 자산과 검증 범위

외부 자산 제작 서비스 금지 이후 작업은 모두 오프라인입니다. 이전에 확보한 CC0 모델을 로컬에서 변환·수정했습니다. 환자의 기존 연결 표면에 목과 다리 길이를 보완하고 Loop subdivision 2회, 민트·크림 옷과 앉은 자세 보정을 적용했습니다. 얼굴 PNG는 같은 GLB를 로컬 WebGL로 렌더한 것입니다. 새 외부 모델·이미지 생성이나 다운로드를 수행하지 않았습니다. [자산 기록](docs/clinic-character-art.json)에 출처·변환 도구·geometry·bone 정보가 있습니다.

Blender 설치·MCP 제작과 가구 GLB 통합은 별도 작업에서 수행됐습니다. 기본 의료도구 6개도 모두 Blender GLB로 교체했고 카트 배치·앉은 자세를 추가 검수 중입니다. 독립 검사 부위 GLB는 같은 Blender 채팅에서 제작 중입니다. 기존 GLB 수정은 Node.js/Three.js와 Python/NumPy로 처리했으며 Blender로 제작한 자산이라고 설명하지 않습니다.

```powershell
npm test
```

`npm test` 84개와 음성 세션·문장 분할·학습 기록의 독립 테스트 24개가 통과했습니다. [가로 화면 보고서](artifacts/landscape-qa-report.json)에서 실제 도구/몸 선택·청진·회전 중 음성/터치 중단·진행 유지·화면 넘침 없음이 확인됐습니다. 네 청진 위치의 소리 종류 매칭 및 당시 8종 기구 검토는 [기존 보고서](artifacts/auscultation-final-full-report.json)에 보존합니다. 이후의 진료실 구도·청진 반응·이경 게임 변경은 별도 브라우저 검증 중입니다. 자동 테스트는 실제 아동의 재미·이해·불안 감소나 임상 효과를 입증하지 않습니다.

부위와 소리는 상징적 교육 시안이며 표준 해부도·임상 청진 자료로 검증되지 않았습니다. 이 개발상 제한을 어린이 화면의 긴 설명으로 표시하지 않습니다. [청진 조작 설계](docs/touch-game-design.md), [아동 심리 설계](docs/child-psychology-design.md), [현재 틀 인계](docs/framework-handoff.md), [자산 제작 인계](docs/image-production-handoff.md)를 다음 작업 기준으로 사용합니다.

최신 수동 입력 계약은 [수동 말하기 계약](docs/manual-voice-contract.md), ASR 힌트 복사 차단과 소량 성인 합성 실증은 [음성 파이프라인 인계](docs/voice-pipeline-handoff.md)에 기록합니다. 의료도구 6종과 독립 검사 부위 7종은 로컬 Blender GLB이며, 최초 표시 전 도구·가구·인물 로딩을 완료하도록 합니다.
